Agri-SDSS

Plateforme de données géospatiales pour la recherche en agriculture durable au Québec. Pipeline automatisé, des données brutes jusqu'aux API conformes OGC, un catalogue STAC, et un assistant IA.

Qu'est-ce qu'Agri-SDSS ?

Agri-SDSS est actuellement spécialisée dans la cartographie du potentiel de la matière organique du sol (MOS) et l'aide à la décision pour les parcelles agricoles du Québec.

L'architecture modulaire basée sur des microservices et Docker rend chaque composant indépendamment réutilisable — le pipeline, les API, le frontend et le chatbot peuvent être adaptés ou remplacés pour d'autres cas d'usage géospatiaux.

Agri-SDSS est un projet de recherche, développé dans le cadre d'une maîtrise à l'Université de Sherbrooke avec un stage de recherche chez Mon Système Fourrager. Il s'agit d'une contribution open source au projet de système d'aide à la décision MOS du RQRAD.

Architecture

La plateforme suit un flux pipeline → stockage → API → frontend : le pipeline géospatial (gis-pipeline) ingère et valide les données sources, les publie dans PostGIS, DuckDB/GeoParquet et des fichiers COG, puis les expose via des API conformes aux standards OGC (STAC, OGC API Features, OGC API Processes) consommées par la carte interactive, le catalogue de données et l'assistant IA.

Standards ouverts et remerciements

Ce projet s'appuie sur des standards ouverts (OGC API Features, STAC) et des logiciels libres. Il s'inspire d'eoAPI (Development Seed), dont l'architecture d'API STAC, raster et vectorielle a servi de point de départ.

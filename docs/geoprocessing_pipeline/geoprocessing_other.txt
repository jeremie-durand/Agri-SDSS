# PIPELINE DE GÉOTRAITEMENTS AUTRES DONNÉES

Input : 
	- Fichier tabulaires ou structurés : csv, json, xml, etc.
	- Règles de mapping : colonnes à extraire, types, correspondanse spatiale possible
	
Output :
	- Données nettoyées et insérées dans PostGIS
	- Jointures spatiales établies (si applicable)
	- Métadonnées STAC créées (même si geometry = null)
	- Données exposées via eoAPI

Outils Python :
	- requests (Send HTTP requets)
	- pandas (Data manipulation)
	- psycopg2 (PostgeSQL adapter)
	- pgSTAC (Python module for PostgreSQL to build STAC catalogs)
	- SQLAlchemy (SQL toolkit for Python)
	- stac-pydantic
	
Étapes :
O1 - Extraction automatique des valeurs importantes, varie selon le cas (pandas)
	Lecture du fichier
	Nettoyage
	Sélection des colonnes clés à conserver
	Si erreur
		Logger l'erreur 
		Passer au fichier suivant

O2 - Intégration des données et métadonnées dans PostGIS - PostgeSQL (psycopg2 / SQLAlchemy)
	Essayer de se connecter à la BD PostGIS
		Si la connexion échoue
			Logger l'erreur
			FATAL ERREUR - arrêt du traitement
	Essayer d'intégrer dans PostGIS
		Si nouvelle donnée
			Créer une nouvelle table
		Essayer d'insérer les données
		Si erreur
			Logger l'erreur
			Passer au fichier suivant
		Essayer d'enregistrer les métadonnées
			Si erreur
				Logger l'erreur
	Confirmer l'intégration des données

O3 - Jointure des données à leur composantes spatiales (si appliquable)
	Si clé de correspondance existe
		Essayer de joindre à une couche spatiale existante
	Sinon
		Logger l'information
		Conserver la donnée, mais avec geometry = null

O4 - Intégration à l'API + publication des métadonnées dans un catalogue STAC (pystac / requests)
	Essayer d'intégrer les données dans l'API via une requête POST
		Si erreur HTTP
			Logger l'erreur
			FATAL ERREUR - arrêt du traitement
		Si erreur de format
			Logger l'erreur
			Passer au fichier suivant
	Publier les métadonnées dans le catalogue STAC (pgSTAC / stac-pydantic)
		Essayer de créer une entrée de métadonnées
			Si erreur
				Logger l'erreur
		Essayer de publier via une requête POST
			Si erreur
				Logger l'erreur
				Passer au fichier suivant
	Confirmer l'intégration et la publication des données et métadonnées dans le endpoint de l'API

	- Nombre de fichiers échoués

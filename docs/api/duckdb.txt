Création du endpoint "/duckdb" dans l'API et des requêtes SQL comme démo.

Pour l'ensemble du containeur : docker compose up --build
Pour uniquement le endpoint duckdb :  docker compose up duckdb --build
Duckdb engine est alors disponible sous : http://localhost:8084/ utilisant Python Flask comme serveur disponible via "/infrastructure/duckdb/app.py".

Les tests pour DuckDB sont disponibles sous "tests/test_duckdb.py"

Il faut suivre les query dans l'ordre :
1. Fetch les données "demo" de PostGIS
2. Regarder si les parquet ont bien été crées 
3. Générer les centroids
---------------------------------------------------
query #1 - fetch-postgis
---------------------------------------------------
La query fetch-postgis permet de fetch des données provenant de tables PostGIS et les sauvegarde dans un fichier Parquet dans DuckDB.
Cette query est basée sur la fonction fetch_postgis() du module "demo/duckdb_utils.py".

curl -X POST http://localhost:8084/fetch-postgis

{"message":"Data fetched and saved to parquet","status":"success"}

---------------------------------------------------
query #2 - check-data
---------------------------------------------------
La query check-data permet de lister les tables disponibles dans duckDB.
Cette query est basée sur la fonction check_data() du module "demo/duckdb_utils.py".

curl -X GET http://localhost:8084/check-data

{"result":["bdppad_2024_4326_sample_stac","sud_du_quebec_4326"],"status":"success"}

---------------------------------------------------
query #3 - generate-centroids
---------------------------------------------------
La query generate-centroids permet de calculer les centroids des géométries dans les tables DuckDB, créant de nouvelles tables pour les stocker et les enregistrer dans des fichiers Parquet.
Cette query est basées sur la fonction get_centroids() du module "demo/duckdb_utils.py".

curl -X POST http://localhost:8084/generate-centroids

{"message":"Centroids computed and saved","status":"success"}

# Product

## Register

product

## Users

Researchers, agronomists, data scientists, and farmers at Mon Système Fourrager and partner institutions, as well as any external collaborator or public stakeholder who needs to discover and access geospatial data. Users range from field researchers and developers familiar with STAC and OGC standards to farmers and non-GIS specialists who need map and catalogue access without a learning curve. The interface must be navigable by someone with no prior knowledge of spatial data standards.

## Product Purpose

Agri-SDSS is a public-facing geospatial data platform for sustainable agriculture research in Quebec. It automates the ingestion, processing, and publication of multi-format GIS data (shapefiles, GeoTIFFs, GeoPackages, CSVs) into a distributed API ecosystem built on open standards: STAC 1.0, OGC API Features, OGC API Processes, and cloud-native formats (COG, GeoParquet). The home portal serves as the entry point — a service navigator linking researchers to the STAC Browser, Raster API, Vector API, and PyGeoAPI. Success means any user can find, preview, and access the right dataset in under a minute.

## Brand Personality

Calm · Professional · Accessible. The platform speaks with the quiet confidence of scientific infrastructure — no urgency, no noise. It is precise without being cold, and welcoming without being casual. Voice is French by default, clear and direct.

## Anti-references

- **Heavy enterprise GIS**: Dense Oracle Spatial / ESRI ArcGIS Portal UIs — crowded navigation, tiny muted text, navy-on-gray color palettes that feel like a 2009 government intranet.
- **Flashy SaaS dashboards**: Gradient blobs, glassmorphism cards, hero-metric templates, startup-style "next-generation geospatial intelligence" copy.

## Design Principles

1. **Data clarity first** — the interface exists to surface data, not to showcase itself. Every element earns its place by helping users reach or understand a dataset.
2. **Quiet precision** — spacing, hierarchy, and color choices should feel deliberate, not decorated. Restraint is the default; embellishment requires a reason.
3. **Spatial grounding** — this is a map-and-terrain tool. Visual decisions should feel connected to the domain: structured grids, clear coordinates, a palette that reads as environment rather than branding exercise.
4. **Accessible expertise** — technical standards (STAC, OGC, COG) are mentioned but never gatekeep. Labels and descriptions work for farmers and non-GIS specialists just as well as for data engineers.
5. **Open by default** — public-facing means no dark patterns, no paywalls, no ambiguity about what each service does or who can use it.

## Accessibility & Inclusion

WCAG 2.1 AA minimum. All interactive elements keyboard-navigable. Contrast ratios: body text ≥ 4.5:1, large text ≥ 3:1. `prefers-reduced-motion` respected for all animations. French as the primary language; English fallback for international collaborators via locale detection.
